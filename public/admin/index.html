Cara Menghubungkan Game ke Telemetri Dashboard Ini

Dashboard ini memiliki endpoint khusus POST /api/track/install. Ketika game dibuka pertama kali oleh anak di ponselnya, game dapat mengirimkan 1 kali HTTP POST request sederhana untuk mencatat bahwa aplikasi telah sukses terpasang dan siap dimainkan.

1. Contoh Implementasi di Unity (C#)

using System.Collections; using UnityEngine; using UnityEngine.Networking; public class InstallTracker : MonoBehaviour { private void Start() { // Jalankan hanya satu kali saat aplikasi pertama kali dipasang if (PlayerPrefs.GetInt("has_tracked_install", 0) == 0) { StartCoroutine(SendInstallPing()); } } private IEnumerator SendInstallPing() { string json = JsonUtility.ToJson(new { version = "v1.1.0", device_id = SystemInfo.deviceUniqueIdentifier, device_model = SystemInfo.deviceModel, os_version = SystemInfo.operatingSystem }); using (UnityWebRequest req = UnityWebRequest.PostWwwForm("https://domain-anda.com/api/track/install", json)) { req.SetRequestHeader("Content-Type", "application/json"); yield return req.SendWebRequest(); if (req.result == UnityWebRequest.Result.Success) { PlayerPrefs.SetInt("has_tracked_install", 1); PlayerPrefs.Save(); } } } }

2. Contoh Uji Coba Cepat via cURL

curl -X POST http://localhost:3000/api/track/install \ -H "Content-Type: application/json" \ -d '{"version":"v1.1.0","device_id":"samsung_sm_a54","device_model":"Samsung Galaxy A54","os_version":"Android 14"}'
